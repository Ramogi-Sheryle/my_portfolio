## Publishing with GitHub Pages
In repository **Settings → Pages**, choose the `main` branch and the `/ (root)` folder, then save. The root-level `index.html` is intentionally kept in place so GitHub Pages can find the website entry page.

## Adding images
Place your profile photo and other portfolio images in `assets/images/`, then reference them from `index.html` using paths such as `assets/images/profile.jpg`.
